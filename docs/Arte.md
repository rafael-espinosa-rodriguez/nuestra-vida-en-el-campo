# Arte — Low-poly inicial + identidad azerbaiyana

## Estilo
3D estilizado low-poly, "realismo cálido" (GDD §§63-66). Nada hiperrealista. Formas simples + luz cálida.

## Paleta MVP (primavera)
- Verdes suaves hierba, flores blancas/rosas/amarillas, madera marrón, piedra gris, techo inclinado rojizo.
- Interior: luz chimenea naranja vs exterior día azul claro; atardecer dorado D7.

## Identidad azerbaiyana (sin estereotipos)
Madera/piedra/barro, techos inclinados, alfombras/textiles en interior, cerámica, pozo de piedra, cercas madera.
Nombres: Misha, Zara, Lola (gallinas). Recetas futuras: plov, qutab (post-MVP).

## Distancias (GDD §67)
Granja→río 30-60s, granja→bosque ~1min, granja→camino pueblo 1-2min. Caminar agradable, nunca tedioso.

## Reglas assets
- Todo pesado (`.png/.glb/.wav`) vía Git LFS. En repo solo `.tscn/.tres/.cs/.md`.
- Escala humana: puerta 2m, gallina 0.3m, vaca 1.4m. Colliders simples (Box/Capsule).
- Sonido primero: viento, gallinas, lluvia, fuego, río, grillos (GDD §37). Música solo momentos (atardecer, chimenea).
